install requirements.txt into python 3.11.14 environment

conda install -c conda-forge porespy

in 'gen_dataset.py' change OUT_DIR (save directory) and N_PER_DEFECT (number of samples generated per defect) to desired values
then run 'gen_dataset.py' in your environment
